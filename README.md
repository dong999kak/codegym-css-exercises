# CodeGym CSS Exercises

This repository contains the implementations prepared for the CSS activities in the CodeGym Web Backend Development with JSP & Servlet course.

| Activity | Description |
| --- | --- |
| 415 | CSS font, border, padding, and ID selector practice |
| 416 | Inline, internal, and external CSS |
| 417 | Styled reading page |
| 418 | Short story reading page with linked contents |
| 430 | CSS box model |
| 431 | Vertical dropdown menu |
| 432 | Horizontal dropdown menu |
| 433 | Semantic HTML5 layout |
| 434 | Responsive social feed layout |
| 435 | Responsive multi-column layout |
| 436 | Cartoon video listing with responsive layout |

Each activity is in its own folder. Activity 436 includes a local video source placeholder in `media/cartoon-intro.mp4`; replace it with a licensed video file if needed.
