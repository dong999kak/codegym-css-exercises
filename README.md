# Activity 471 — JSP/Servlet login

Maven WAR for Tomcat 10.1+ (Jakarta Servlet 6). Open `/jsp-servlet-login/`, submit `admin` / `admin` to see `Welcome admin to website`; any other credentials show `Login Error`. Build with `mvn clean package` and deploy `target/jsp-servlet-login.war` to Tomcat. The server was not started or deployed in this environment.
